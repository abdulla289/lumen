# Lumen

Lumen помогает руководителю отдела продаж отслеживать работу торговых представителей, находить отклонения в магазинах и проверять, почему торговое оборудование не приносит ожидаемых продаж.

## Что работает в демо

- **Руководитель** видит продажи, месячную прибыль, рейтинг по заказам, оборудование и отчёты. Он может назначать задачи, отмечать визиты команды и своё присутствие на встречах.
- **Торговый представитель** видит личное расписание, задачи и статистику. Он может отметить выполнение задачи, перенести пропущенный визит и отправить сводку руководителю.
- **«Лари и трафик»** показывает по дням посещаемость, продажи товаров из ларя, наличие товара и состояние ларя. Для точек с нулевыми продажами система предлагает, что проверить.

## Используемые инструменты и технологии

- **HTML5, CSS3 и JavaScript.** Разметка, адаптивное оформление, графики и расчёты выполняются в браузере.
- **Браузерные API.** `localStorage` хранит отметки и задачи в одном браузере. `Intl` форматирует даты, проценты и суммы. Экспорт визита в календарь работает через файл `.ics`.
- **Git и Codex.** Git использовался для хранения версий, Codex помогал писать и проверять код.

Опубликованная веб-версия запускается без сборки, серверного движка, внешних библиотек и внешних API. Первая локальная версия дашборда была написана на Python 3.12 с библиотеками Streamlit и Altair.

## Исходные данные и расчёты

Встроены вымышленные данные шести точек в Актобе. Объёмы продаж, заказы, посещаемость и результаты проверки ларей служат примерами отличающихся сценариев.

- Выполнение плана = выручка / план × 100%.
- Операционная прибыль = выручка − себестоимость товаров − операционные расходы.
- Эффективность сотрудника учитывает выполнение плана (50%), долю состоявшихся визитов с отметкой (30%) и выполнение задач со сроком в периоде (20%). Если данных по показателю нет, его вес пропорционально распределяется между остальными.

Демо-профили выбираются без регистрации. Отметки хранятся в браузере и не синхронизируются между устройствами.

## Как посмотреть демо

1. Откройте главную страницу. В правом верхнем углу выберите **«Кабинеты» → «Руководитель»**.
2. В разделе **«Лари и трафик»** выберите «Арман». В примере за день зашло 92 человека, продаж из ларя не было, при проверке компрессор не запустился.
3. В разделе **«За месяц»** посмотрите рейтинг точек по числу заказов и расчёт операционной прибыли.
4. Для просмотра личного расписания и задач выберите **«Кабинеты» → «Торговый представитель»** и откройте демо-профиль.

## Публикация через GitHub Pages

Загрузите `index.html`, все `.css` и `.js` из папки `dist` и файл `.nojekyll` в корень публичного репозитория `lumen`. Если вы используете архив для GitHub Pages, распакуйте его и загрузите содержимое. В **Settings → Pages** выберите **Deploy from a branch → main → /(root)**. GitHub покажет опубликованный адрес в настройках Pages.

[Официальное руководство GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
